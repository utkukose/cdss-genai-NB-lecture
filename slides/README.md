# Slides

The presentation decks are generated from the lecture notes in `lecture/` using NotebookLM
and are added to this folder after the session, as PDF.

Expected file names, which the links in `README.md` and `README.tr.md` already point to:

| File | Language | Source text |
|---|---|---|
| `CDSS-lecture-slides-EN.pdf` | English | `lecture/CDSS-lecture-notes-EN.pdf` |
| `KKDS-ders-sunumu-TR.pdf` | Türkçe | `lecture/KKDS-ders-notlari-TR.pdf` |

Sunum dosyaları, `lecture/` klasöründeki ders notlarından NotebookLM ile üretilmekte ve
oturumdan sonra PDF olarak bu klasöre eklenmektedir. Beklenen dosya adları yukarıdaki
tabloda yer alır; iki README dosyasındaki bağlantılar bu adlara işaret eder.
