# Regulatory Triage · Düzenleyici Triyaj

Bu belge hukuki görüş değildir ve yerine geçmez. Bir hukukçuya ya da düzenleyici uzmana
gitmeden önce hangi soruların cevaplanmış, hangilerinin açık olduğunu ortaya koymak için
kullanılmaktadır.

Tarihler Eylül 2026 itibarıyla geçerlidir. Bu alan hareketlidir; belgeyi yeniden
kullanmadan önce dört başlığın tamamı güncellenmelidir.

---

## 0. Kullanım notu

Yedinci istem bu belgenin bir taslağını üretmektedir. Üretilen taslağa **mutlaka**
sorgulama istemi uygulanmalıdır. Düzenleyici sorular kendinden emin icadı davet etmekte,
ayrıca bu alandaki uyum tarihleri Temmuz 2026'da değişmektedir; pek çok asistan hâlâ eski
takvimi döndürecek kadar yeni bir değişikliktir.

Her maddede iki alan bulunmaktadır: Cevap ve **bir hukukçunun kontrol etmesi gereken
nokta.** İkincisi boş bırakılamaz.

---

## 1. Bu bir tıbbi cihaz mı?

Avrupa Birliği'nde değerlendirme, Tıbbi Cihaz Tüzüğü (AB) 2017/745 ve yazılımı
sınıflandıran Ek VIII Kural 11 üzerinden yapılmaktadır.

| Soru | Cevap |
|---|---|
| Üretici tarafından beyan edilen amaç nedir | |
| Bu amaç teşhis ya da tedaviye yönelik mi | |
| Çıktı bir karar mı yoksa bir gerekçe mi sunuyor | |
| Kural 11 kapsamında sınıf ne | |
| **Hukukçunun kontrol etmesi gereken** | |

Amaç beyanının kendisi belirleyicidir. Aynı yazılım, farklı bir amaç beyanıyla farklı bir
düzenleyici konuma düşebilmektedir.

---

## 2. Avrupa Birliği Yapay Zekâ Yasası

Yasa AB 2024/1689 sayılı Tüzük ile 1 Ağustos 2024 tarihinde yürürlüğe girmiştir. AB
2026/1744 sayılı Dijital Omnibus düzenlemesi 24 Temmuz 2026 tarihinde yayımlanmış, 27
Temmuz 2026 tarihinde yürürlüğe girmiş ve yüksek risk yükümlülüklerinin uygulama
tarihlerini değiştirmiştir.

| Kapsam | Uyum tarihi |
|---|---|
| Madde 50 şeffaflık yükümlülükleri | 2 Ağustos 2026, ertelenmedi |
| Yeni Madde 5 yasakları ve mevcut sistemler için filigran | 2 Aralık 2026 |
| Ek III bağımsız yüksek riskli sistemler | 2 Aralık 2027, eski tarih 2 Ağustos 2026 |
| Ek I gömülü sistemler, tıbbi cihaz içindeki yapay zekâ dâhil | 2 Ağustos 2028, eski tarih 2 Ağustos 2027 |

| Soru | Cevap |
|---|---|
| Sistem hangi eke giriyor | |
| Geçerli uyum tarihi | |
| Madde 13 şeffaflık gereklilikleri nasıl karşılanacak | |
| İnsan gözetimi nasıl belgelenecek | |
| **Hukukçunun kontrol etmesi gereken** | |

Ertelemenin hazırlığın ertelenmesi anlamına gelmediği not edilmelidir. Uygunluk
değerlendirmesi, teknik dosya ve insan gözetimi tasarımı, tarih geldiğinde
tamamlanmış olmalıdır.

## 3. Amerika Birleşik Devletleri

Federal Gıda, İlaç ve Kozmetik Kanunu'nun 21st Century Cures Act ile eklenen 520(o)(1)(E)
maddesi, bir karar destek yazılımının cihaz tanımı dışında kalabilmesi için dört ölçüt
aramaktadır.

| Ölçüt | Karşılanıyor mu | Gerekçe |
|---|---|---|
| Tıbbi görüntü, sinyal ya da örnekten elde edilen veriyi işlemiyor | | |
| Tıbbi bilgi ya da hasta bilgisini gösteriyor, analiz ediyor ya da işliyor | | |
| Sağlık profesyoneline seçenek sunuyor, tek bir karar dayatmıyor | | |
| **Sağlık profesyoneli önerinin dayanağını bağımsız gözden geçirebiliyor** | | |

Dördüncü ölçüt açıklanabilirliğin hukuki karşılığıdır ve bu atölyede kurulan sistemin
neden katkı dökümü gösterdiğinin sebebidir.

| Soru | Cevap |
|---|---|
| Cihaz sayılıyorsa hangi yol izlenir | |
| Öğrenen bileşen varsa önceden belirlenmiş değişiklik kontrol planı gerekli mi | |
| **Hukukçunun kontrol etmesi gereken** | |

Not: FDA'nın yayımladığı yapay zekâ destekli cihaz listesinde bugüne kadar üretken yapay
zekâ ya da büyük dil modeliyle çalışan yetkilendirilmiş bir cihaz bulunmamaktadır.

## 4. Türkiye

Türkiye'de yapay zekâyı doğrudan düzenleyen müstakil bir kanun bulunmamaktadır. Sorumluluk
mevcut mevzuat katmanlarının birlikte uygulanmasıyla belirlenmektedir.

| Katman | Soru | Cevap |
|---|---|---|
| Tıbbi cihaz mevzuatı | Yazılım cihaz sayılıyor mu, kayıt gerekli mi | |
| 6698 sayılı Kanun | Sağlık verisi özel nitelikli kişisel veridir; işleme şartı hangisi | |
| 6698 sayılı Kanun | Açık rıza mı, başka bir işleme şartı mı | |
| 6698 sayılı Kanun | Veri minimizasyonu nasıl sağlanıyor | |
| 6698 sayılı Kanun | Yurt dışına veri aktarımı var mı | |
| Malpraktis rejimi | Aydınlatılmış onam kapsamına yapay zekâ kullanımı giriyor mu | |
| Malpraktis rejimi | Hata hâlinde sorumluluk kimde | |
| 2026/9 sayılı Genelge | Kurumun Eylem Planı kapsamındaki yükümlülüğü etkiliyor mu | |
| **Hukukçunun kontrol etmesi gereken** | | |

Bulut tabanlı ya da yurt dışı bir dil modeli kullanılıyorsa, hasta verisinin o servise
gönderilip gönderilmediği ayrıca ve açıkça cevaplanmalıdır. Atölyede kurulan sistemlerde
hiçbir gerçek hasta verisi dil modeline gönderilmemektedir; kendi kurumunuzda aynı şeyin
geçerli olduğunu varsaymayınız.
